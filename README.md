## HRMS Setup

1. Configure the active database in `.env`, then set `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, and `CLOUDINARY_API_SECRET`. Keep the Cloudinary secret server-side.
2. Run `php artisan migrate` to create the schema, Sanctum token storage, and HRMS upload metadata.
3. Run `php artisan hrms:install` only on a fresh database. It seeds demo employees and operational records; `--force` truncates existing HRMS tables. Never run it against production data.
4. Start the API with `php artisan serve`. Sign in through the frontend; protected API routes and private file downloads require an authenticated account.

To clear demo operational data while retaining the organization masters and linked super-admin profile, preview first with `php artisan hrms:clean-operational-data --database=HRMS_DB`, then add `--force` to apply the cleanup.
